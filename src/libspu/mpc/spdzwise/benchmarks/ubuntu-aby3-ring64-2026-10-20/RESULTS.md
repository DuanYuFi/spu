# 原生 ABY3 环电路实验（2026-10-20）

已运行 SPU 原生 ABY3，FM64，算术模数为 2^64。调用原生 Aby3Io、add_ap、add_aa、mul_aa；不调用 F61 适配运算。源码增加可选 `ring64` 参数，默认 F61 实验模式保留。

电路：`z[0,i]=x+i`，`z[l+1,i]=z[l,i]*(z[l,i]+y)`，全部按模 2^64 运算。宽度 65,536、深度 16，共 1,048,576 个秘密乘法门和同等数量的秘密加法门；仅两个秘密输入，x=2^60-8，y=-13。无定点截断。

环境：Ubuntu 24.04.3 LTS，双路 Xeon Gold 6248R，48 物理核 / 96 逻辑 CPU，GCC 13.3.0，Bazel 7.7.1，`-c opt`。三方同进程 FactoryMem，YACL 95 个 worker；未绑定 CPU 或隔离其他负载。

预热 1 次，测量 7 次；每轮各阶段取三方最大值，再对七轮取中位数。总耗时先逐轮相加再取中位数，因此各列中位数不必相加一致。

| 指标 | 中位数（ms） |
|---|---:|
| 公开展开 | 0.775 |
| 电路计算（加法+乘法） | 39.344 |
| 其中乘法 | 27.577 |
| 最终 verification | 0.000 |
| 全部计时阶段 | 40.096 |

电路耗时范围：38.184–43.641 ms。每方每轮电路发送 8,388,608 B（8 MiB），三方发送合计 24 MiB；公开展开不通信。没有 MAC 或恶意安全检查。

最后一轮全部 65,536 个输出与 uint64 明文模环计算逐元素一致。统计脚本验证 21 条样本、三方身份、七轮索引、门数和通信量。原有 F61 两协议模式另以宽度 8、深度 2、一次测量完成回归，输出核对通过。

计时排除初始分享、协议/PRSS 初始化、输出重构及明文核对。上述结果为本机内存通信的整数电路性能，不是跨机网络或完整 PPML 模型性能。
